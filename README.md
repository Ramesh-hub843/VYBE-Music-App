# VYBE 🎧

Premium iOS-inspired music player for Android, built with Expo + React Native.

## V1
- Local audio file import
- Real audio playback
- Home, Search and Library tabs
- Mini player
- Favorites
- Premium dark/glass aesthetic

## Run
```bash
npm install
npx expo start
```
Then press `a` for Android or scan the Expo QR code with Expo Go.

> Only import/play music you own or have permission to use. VYBE does not download or redistribute copyrighted streaming content.
